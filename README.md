# Vapesoon.arg

Landing page de e-commerce para Vapesoon, un emprendimiento de venta de vapes en Hurlingham, Zona Oeste (Buenos Aires).

Sitio de una sola página (single-file), sin backend ni build: todo el HTML, CSS, JS e imágenes están embebidos en `index.html`. Se puede abrir directamente en el navegador o publicarlo en cualquier hosting estático (Netlify, Vercel, GitHub Pages, etc.).

## Estructura
- `index.html` — sitio completo (catálogo, carrito, reseñas, WhatsApp, etc.)

## Deploy
Pensado para deploy estático directo, sin pasos de build.
